# 📈 Sentimenti i Lajmeve → Borsa (ML)

Notebook-u origjinal përdor **Bag-of-Words + Logistic Regression / Random Forest / Naive Bayes** mbi mijëra tituj lajmesh (`Stock Headlines.csv`, 25 tituj/ditë) për të parashikuar nëse indeksi **Dow Jones** ngrihet apo bie. Demoja është **simulim edukativ**: analizon 10 tituj shembull me fjalor sentimentesh, tregon matësin dhe jep parashikimin — plus mund të analizosh titullin tënd.

## Si ta hapësh

Hap `index.html` në browser — tab-i **Live Demo** tregon demon funksionale, tab-i **Kodi Burim** tregon të gjithë kodin.

Ose hap direkt `demo/index.html` për demon.

## Struktura

- `index.html` — faqe showcase (Live Demo + Kodi Burim)
- `demo/` — demo/index.html (simulim), original/Stock Sentiment Analysis.ipynb, original/Stock Headlines.csv
- `original/` — burimi origjinal i paprekur
